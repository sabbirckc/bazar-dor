
# বাজার দর (BazarDor)

**BazarDor** is a Bangla-language market price website that helps users easily check the current prices of essential daily products in Bangladesh. It provides a simple, responsive interface to explore product prices and track price changes.

## Technologies Used

- **Next.js** — React framework for building the web application
- **React** — Component-based user interface
- **TypeScript** — Type-safe development
- **Tailwind CSS** — Responsive styling and layout
- **daisyUI** — Tailwind CSS component library
- **Better Auth** — User authentication
- **MongoDB** — Database integration
- **External REST APIs** — Product and market price data

## Key Features

1. **Live Market Price Ticker** — Displays product prices and price changes in a scrolling ticker.
2. **Price Increase and Decrease Tracking** — Shows products whose prices have increased or decreased.
3. **All Products Listing** — Displays essential products with their current prices.
4. **Category-Based Browsing** — Allows users to explore products by categories such as rice, lentils, oil, vegetables, fish, and meat.
5. **User Authentication** — Supports account registration, sign-in, and profile access.
